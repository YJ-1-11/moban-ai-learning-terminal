# Moban Hardware Design

## 项目简介
本目录用于存放墨伴（Moban）智能桌面学习终端的硬件设计资料，包括原理图、PCB、元器件清单及相关设计文档。

## 硬件配置
- 主控：ESP32-S3-WROOM-1-N16R8
- 显示：4.2 英寸电子墨水屏（400 × 300）
- 音频：麦克风采集、音频功放及扬声器
- 存储：MicroSD
- 电源：锂电池、USB 充电及电源管理
- PCB：四层板设计
